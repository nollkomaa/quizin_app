# Fungsi Folder
Penyimpanan konfigurasi

# Rincian
- constants/: Menyimpan variabel tetap seperti URL API Backend (http://...), warna utama aplikasi, atau teks konstanta.

- theme/: Pengaturan tema aplikasi (warna light/dark mode, gaya font tulisan).

- routes/: Pengaturan navigasi perpindahan halaman aplikasi.

- utils/: Fungsi pembantu (misal: format tanggal, kalkulasi nilai/skor, validator input).
