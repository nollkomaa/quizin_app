# Fungsi Folder
Pengelola dan penyimpanan data yang perubahannya harus langsung terlihat di layar HP secara real-time.

# Contoh

- Status apakah pengguna saat ini sudah dalam keadaan login atau belum.

- Jumlah koin, poin, atau XP yang bertambah secara langsung saat pengguna berhasil menyelesaikan kuis.

- Catatan jawaban kuis yang sedang dipilih oleh pengguna secara real-time sebelum akhirnya dikirim ke server.
