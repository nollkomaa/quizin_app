# Rincian

- splash/: Halaman awal (logo loading) saat aplikasi pertama dibaca.

- auth/: Halaman Login & Register.

- home/: Tampilan beranda utama aplikasi.

- materi/: Tampilan daftar dan detail bacaan materi.

- quiz/: Layar tempat pengerjaan kuis/soal interaktif.

- pembahasan/: Halaman review/penjelasan kunci jawaban setelah kuis selesai.

- profile/: Tampilan data pengguna.

- shop/: Toko tempat penukaran koin/skor dengan barang/karakter.

- leaderboard/: Layar peringkat skor tertinggi antar pengguna.

- progress/: Layar pelacak riwayat dan persentase belajar.

- settings/: Halaman pengaturan aplikasi.
